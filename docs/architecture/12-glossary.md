# 12. Glossary

The glossary lives in one place, [`GLOSSARY.md`](../../GLOSSARY.md) at the repo root, so code, UI and docs share it. It covers the room (station, board, organiser), play (match, leg, visit, takeout, bust, in and out rules), tournaments (group, seed, rating, knockout, walkover) and stats.

Abbreviations used in these docs:

| Term | Meaning |
|---|---|
| ADR | Architecture decision record, in `docs/adr/` |
| SSE | Server-Sent Events, the one-way live stream from the server to the browsers |
| Org, Pla, Spe, Ops, Dev | Organiser, players, spectators, operator, developer (the "For" column in sections 1.1 and 10) |
| PLAY-, BOARD-, PLAYER-, MATCH-, TOUR-, SCHED-, VIEW-, RATING-, STATS-, ADMIN-, OPS- | Functional requirement IDs (section 1.1) |
| Q-, QS- | Quality requirement and quality scenario IDs (section 10) |
